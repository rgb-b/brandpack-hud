## 🎯 How To Use

### The Launcher (Your Home Base)

1. Open **brandpack-tools-launcher.html**
2. You'll see two tabs:
   - **🏠 Home** - Launch tools and manage data
   - **📊 Analytics** - View comprehensive statistics

### Using The Tools

**From the launcher, click any tool card:**

- **📦 Inventory System** - Track ink, media, supplies
- **⏱️ Productivity Tracker** - Track your time
- **🎨 Pantone Tracker** - Check color matches
- **🔄 LAB Converter** - Convert LAB to CMYK

**Each tool has a "← Back to Launcher" button** to return to the home screen.

### Data Management

**Export All Data:**
1. Click **💾 Export All Data** on launcher
2. Saves ONE file with data from ALL tools
3. Keep this file as backup

**Import All Data:**
1. Click **📥 Import All Data** on launcher
2. Select your backup JSON file
3. All tools now have the imported data

## 📊 Tools Overview

### 1. Productivity Tracker
- Track time: Available, Working, Unavailable
- Custom tasks for each category
- Daily summaries
- **🌙 End Work Day button** - Stops tracking and saves

### 2. Inventory System
- Track all printer supplies
- Monitor stock levels
- Usage history
- Add custom items
- Low stock warnings

### 3. Pantone Tracker
- 4,150+ Pantone colors (COATED library)
- Check if colors are matched
- Search single or multiple colors
- Warnings for colors 5+ years old
- Update match dates

**First time using Pantone Tracker:**
1. Open pantone-tracker.html
2. Upload pantone_data.json (one-time only)
3. Data saves in browser

### 4. LAB-CMYK Converter
- Convert LAB values to CMYK
- Convert CMYK values to LAB
- Real-time conversion
- Live color preview
- No data storage (instant tool)

## 💾 Moving Between Computers

### On Computer A (e.g., Laptop)
1. Open launcher
2. Click **💾 Export All Data**
3. Save the JSON file
4. Copy ALL HTML files + JSON backup to USB

### On Computer B (e.g., Work PC)
1. Copy all files from USB to a folder
2. Open **brandpack-tools-launcher.html**
3. Click **📥 Import All Data**
4. Select your backup JSON file
5. ✅ Everything is now synced!

## 🆘 Troubleshooting

### "Tool doesn't load"
- Make sure all files are in the same folder
- Check that file names haven't changed

### "Data not showing in launcher"
- Click back from a tool to auto-refresh stats
- Or refresh the launcher page (F5)

### "Import fails"
- Make sure you're using a file exported from Brandpack Tools
- Check the file is valid JSON format

### "Pantone Tracker empty"
- Need to upload pantone_data.json on first use
- File is included in your download
